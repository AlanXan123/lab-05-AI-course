## Повторный запуск в Google Colab при необходимости

1. Открой https://colab.research.google.com/ и выбери **File → Upload notebook**.
   Загрузи локальный `lab05_harness.ipynb` из этой папки. Если открыть исходный
   ноутбук преподавателя по его ссылке, в нём снова будут незаполненные TODO.
2. Выбери **Runtime → Change runtime type → T4 GPU → Save**.
3. Выполняй ячейки по одной сверху вниз. Первая устанавливает зависимости,
   следующая скачивает исходные CSV, затем загружается модель около 6,2 ГБ.
4. До загрузки модели запиши личное предположение в `PREDICTION_0`.
   До сравнительного прогона заполни `PREDICTION_1`. После него запиши реальные
   наблюдения в `OBSERVATION_1`.
5. В Part 2 цикл уже реализован. Запусти `check_loop`: ожидается `all three match`.
   Затем запусти пример `q21` и заполни `LOOP_NOTES` по фактическому поведению.
6. До прогона слоёв заполни `PREDICTION_3`, затем выполни Part 3.
   Посмотри таблицу исходов и trace ошибочного ответа слоя 3. Заполни `OBSERVATION_3`.
7. В `NOTES` добавь процедуры и соглашения на основе увиденных ошибок: например,
   как выбирать канонические названия регионов и различать город и область.
   Не записывай туда численные ответы. Выполни Part 4 и заполни `OBSERVATION_4`.
8. В последней ячейке у всех восьми переменных должно быть `filled in`.
   Сохрани ноутбук с outputs через **File → Download → Download .ipynb**
   и замени им локальный файл.

## Заключение и сдача

`CONCLUSION.md` по условию нужно написать самостоятельно, без ИИ,
по 80–200 английских слов на каждый из трёх вопросов. Сохрани заголовки
и последнюю строку. Все цитируемые числа бери только из своего прогона.
В шаблоне есть устаревшие упоминания 20 вопросов и q01–q20: фактический
ноутбук содержит 24 вопроса. Не пересчитывай результаты искусственно до 20.

Для сдачи нужен fork на твоём GitHub, выполненный ноутбук и личное заключение.
В Canvas отправляется ссылка на последний commit. Дополнительные задания
из раздела Extension tasks не заменяют Parts 0–4.

## Локальная проверка кода без модели

```powershell
python -m unittest -v test_agent_loop.py
```

Тесты используют заранее заданные ответы, реальные парсер и инструменты.
Они не заменяют `check_loop` с настоящей Qwen и полный эксперимент в Colab.
